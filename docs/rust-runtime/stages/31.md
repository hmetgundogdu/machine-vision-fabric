## What was built

- **The TUI** (`crates/mvf-cli/src/tui/`, Ratatui 0.30 + crossterm, pure Rust). It is a
  management client, so it goes through the same feed, roles, validation and audit as
  `manage watch` and `manage command`. Usage, keys and the legacy comparison are in
  [tui.md](../tui.md).
  - `layout`: the legacy layers (longest path from a source, 22×5 boxes, 18-wide columns), with
    dummy rows for long edges, barycentre ordering and a track per edge.
  - `state`: the model, built from the snapshot and the stream and replaced on a gap. It handles
    keys, typed validation of edits, and command replies. Memory is bounded.
  - `render`: the legacy palette and look:
    - ASCII only: borders, icons, spinner, shafts, sparkline;
    - a breathing border on the running node, an afterglow, comets on data edges;
    - viewport scrolling for wide graphs;
    - detail panels, an in-terminal preview (24-bit colour or an ASCII ramp), help.
  - `image`: decodes the runtime's stored-deflate preview PNGs and refuses anything else.
  - `mod`: the event loop:
    - feed, command and preview threads, so the UI never waits on the runtime;
    - reconnect from the last sequence, or from a snapshot when the runtime is a new one;
    - exit 2 without an interactive terminal;
    - `--print` renders one frame as text.
  - **`mvf run --tui`:** implies `--manage`; record and log printing stay off while the dashboard
    owns the screen. `q` stops the run, and a TUI panic restores the terminal and leaves the run
    going. The report is printed after the dashboard closes.
- **Telemetry, in the runtime:**
  - **Running now:** `Observer::node_started` / `node_stopped` / `wants_activity`.
    - The serial executor reports every start. A cycle that ends early reports the node it
      stopped.
    - The pipelined driver reports sources. Stages send a `Started` event only when the observer
      asks for activity.
    - The Tap counts executions in progress with relaxed atomics. A feed thread samples them
      every 100 ms and publishes `activity` entries; the snapshot carries `activity`.
    - It is never inferred from completed-node counters.
  - **Per-node counters:** `failures`, `restarts` and `dropped`, from the recovery events.
  - **After a replacement or rollback:** the active `contract` and `backend`.
    `ReplacementEvent.backend` is new.
  - **`topology.live`:** each editable field's command, type, shape, schema and binding key,
    never its value.
- **Previews:** a BMP-encoded blob is decoded (uncompressed 8/24/32-bit; offsets checked; only
  the downscaled pixels sampled). PNG- and JPEG-encoded blobs and unknown blobs are named, never
  drawn as raw pixels.
- **Engine fix:** `wait_while_paused` never handed events to the observer. The `paused` event,
  and edits made while paused, reached management only after `resume`. A `pause` command could
  only come back `pending`, and no client could show the graph as paused. The boundary hook now
  passes the observer through.

### Cost on the engine thread (release, macOS)

| | before (stage 28) | now |
|---|---|---|
| serial, 64×48 RGB, management Tap, previews off | 11.13–11.37 µs/cycle | 10.49–10.81 µs/cycle |
| pipelined, Tap (activity events on), previews off | 12.21–12.26 µs/cycle | 11.98–12.20 µs/cycle |

Within noise. The serial path no longer publishes from `node_started` at all: it does one atomic
add per start and a saturating subtract per end.

## Limits

- **Current values of editable fields are not shown** (ADR-0007: config values never leave the
  runtime). The TUI shows what it set itself.
- **Not yet in management, so not shown:** worker CPU and memory, and the source receive/queue
  split.
- **Shared attachment rows:** a node with more than three edges on one side shares attachment
  rows.
- **Windows:** no interactive Windows Terminal session runs in CI, because hosted runners give
  no console a test can drive. The Windows checks are the cross-lint, the rendering tests and
  `manage tui --print` over the named pipe.
- **No side-by-side capture with the legacy TUI;** the look is ported from its source code.
