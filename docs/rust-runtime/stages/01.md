# Stage 01 — Rust workspace and Universal Node Contract (#11)

**Status: PASS** (macOS arm64 locally; Windows/Linux via the new CI matrix job)

## What was built

- `rust/` Cargo workspace (edition 2024, resolver 3), `rust/rust-toolchain.toml` pinned to
  **1.95.0** with rustfmt + clippy, `rust/Cargo.lock` committed, `rust/clippy.toml`.
  Location rationale in [../README.md](../README.md#layout-decision).
- `mvf-contract` crate, no host-specific dependencies (only `serde`, `serde_json`,
  `serde_path_to_error`, `saphyr-parser`, `semver`, `thiserror`):
  - `yaml` — strict bounded loader: single document, no anchors/aliases/tags, duplicate-key and
    complex-key rejection, size/depth/node/scalar limits, conservative YAML 1.2 core-schema scalars;
  - `model` — typed contract with `deny_unknown_fields` everywhere and closed enums: identity and
    semver, typed data/control ports, per-backend artifacts, placement + fallback, explicit
    isolation levels, memory domain + zero-copy, lifecycle (activation, timeouts, replacement,
    versioned state), resources + enforcement;
  - `validate` — semantic checks with 33 stable codes and field paths, all issues reported at once;
  - `negotiate` — backend capability negotiation returning a placement with notes or a structured
    rejection per candidate; pinned backends and `fallback: deny` are never weakened.
- CI: new `rust` job (ubuntu/windows/macos) running fmt, clippy `-D warnings`, `test --locked`.
  The existing `.NET`, Python SDK, TS client and C++ SDK jobs are untouched.
- Docs: [node-contract.md](../node-contract.md), [parity-matrix.md](../parity-matrix.md).

## Limitations

- `v1alpha1` is a research schema; field names may change before the ADR (#16).
- Only the contract exists: no backend implements these capabilities yet (#13 onward).
- An alias can only follow an anchor; anchors are rejected first, and an alias to an unknown anchor
  is a parser syntax error, so `yaml.alias-forbidden` is defensive and not reachable by a fixture.
- Unsafe code: none.
