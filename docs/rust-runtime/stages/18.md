## What was built

- **Contract.**
  - `permissions.display`: `mode: none | native | managed-surface`, `required`, `maxWindows`,
    `maxWidth`/`maxHeight`, `keyboard`, `mouse`, `clipboard`, `fullscreen`.
  - `spec.presentation { title, width, height }`.
  - Validation codes `contract.display.*`.
- **Negotiation.**
  - `BackendCapabilities.display` lists native, managed surface, fullscreen and the session.
  - Rejections: `negotiation.display-unavailable`, `-clipboard-unsupported`,
    `-fullscreen-unsupported`.
  - Notes: `placement.display-headless`, `placement.display-input-unmediated`.
- **`mvf-display`** (no window dependency):
  - session probe for Aqua via `SessionGetInfo`, X11/Wayland sockets, and Windows session id plus
    window station;
  - surface format v1 ([`protocol/display-surface.md`](../../protocol/display-surface.md)):
    `SurfaceWriter` / `SurfaceReader`, three buffers, CRC-verified frames and input, file-lock
    ownership;
  - the per-user registry, with sweeping of dead runs.
- **Engine and worker.**
  - `HostServices.display` allocates surfaces per pipeline node.
  - A worker gets `MVF_DISPLAY_SURFACES`.
  - Nodes without `native` do not inherit `DISPLAY` / `WAYLAND_DISPLAY` / `XAUTHORITY`
    (`LaunchSpec.remove_env`).
  - The effective grant is logged.
- **Python SDK** `mvf_sdk.display` (stdlib only): `surfaces()`, `Surface.present()`,
  `poll_input()`, `host()`.
- **`modules/py-camera-preview`.** Business logic only:
  - window 1 is the live view; a click sets the region and draws a crosshair;
  - window 2 is a detail view of that region;
  - the JSON output reports the region, so a click becomes typed data.
- **`mvf-display-host`** (winit 0.30 + softbuffer 0.4):
  - discovers surfaces and opens one window per surface;
  - letterboxes the frame and maps input back to frame pixels;
  - grants-only routing, plus focus/resize/close/DPI handling;
  - heartbeat;
  - `--headless`, `--probe`, `--stats`.
- **`mvf-cube`** (Rust renderer node, links no window library):
  - the camera frame is the front face of a CPU-rasterized cube;
  - drag to orbit, wheel to zoom, `r` to reset;
  - renders at the host's requested size and keeps working headless when its window closes.
- **`mvf-native-window`.** The native-UI proof of concept: an "existing app" that opens its own
  window and draws frames. MVF only gates it on the session.
- **Demo.** `rust/examples/display-demo` and `rust/scripts/display-demo.sh`: camera → preview
  plus 3D inspector, host in the desktop session.

### Latency and cost

| Measurement | macOS (M-series) | Linux (aarch64 VM) |
|---|---|---|
| 1920×1080 BGRA, Rust present (copy + CRC), release | p50 0.34 ms, p99 0.43 | p50 0.36 ms, p99 0.47 |
| 1920×1080 BGRA, host verified copy-out, release | p50 0.23 ms, p99 0.35 | p50 0.35 ms, p99 0.43 |
| 1920×1080 BGRA, Python `present()` | p50 0.34 ms | p50 2.01 ms (Debian zlib CRC without hardware acceleration) |
| Python preview 64×48 at 40 fps, present → host copy (host polls ~2 ms), debug | p50 1.64, p95 2.41, p99 2.57 ms | — |
| Real window, present → host copy (host polls 4 ms), debug | p50 2.5–3.7, p99 7.9–13.2 ms | X11 p50 3.0–4.9; Wayland p50 3.1–3.9 ms |
| 500 presents, 320×240, no host, release | 5.4 ms total, worst 35 µs | — |
| Demo (release): cube 800×600 render / preview 640×360 node time | 3.7 ms / 0.45 ms per frame | — |

The host copies each frame once into its window buffer, and that copy is also its integrity check.
Polling adds up to one poll interval of latency; a doorbell is a future option. CPU/GPU
utilisation and process-tree RAM on industrial hardware are P4.

## Limits

- **Trusted nodes are not confined.** A worker is not sandboxed: withholding the display
  environment is hygiene. A native node's input is not mediated.
- **The host polls** (2–4 ms); there is no doorbell yet.
- **Detection delay:** a crashed host counts as attached for up to 2 s (heartbeat staleness).
- **No GPU interop:** frames are CPU BGRA/RGBA/RGB/gray, up to 8192×8192 per surface.
- **Not grantable yet:** fullscreen and clipboard requests are rejected.
- **Wayland windows have no decorations** under compositors without server-side decorations
  (winit built without `sctk-adwaita`).
- **Not done yet:** OCI presentation, live replacement keeping the window, the inspector, the
  Studio and the Windows service host are part 2 and later.
