# Stage 04 — CPU shared-memory data plane and protocol parity slice (#14)

**Status: PASS** (macOS arm64 locally; Linux/Windows in CI, C++ interop required there)

## What was built

- **Arena-resident payloads**: `Payload::Arena(Lease)` next to `Payload::Heap(Arc<[u8]>)`.
  Cloning a value clones the lease (reference count + 1); the slot is reclaimed when the last
  consumer drops it at the end of the cycle — the dynamic equivalent of the .NET graph-derived
  refcounts, with no stale counts possible.
- **Zero-copy worker hand-off**: a frame already in the engine arena is handed to a worker by
  `shm.offset` (counted as a zero-copy hand-off); a heap frame is copied in once (counted). A
  worker's output is sealed **in place** and travels downstream as a lease — nothing is copied
  out. Workers now advertise `zeroCopyDomains: [host]` honestly.
- **Producer writes into the arena**: `synthetic-source` with `arena: true` writes pixels straight
  into a reserved slot (a *transform write*, not a transfer copy).
- **Accounting** (`RunReport.dataPlane`): arena counters `copiesIn`/`bytesCopiedIn`,
  `copiesOut`/`bytesCopiedOut` (transfer copies), `transformWrites`/`transformBytes` (producers
  writing their own new output), `zeroCopyHandoffs`, `reclaimed`, `admissionRefusals`, `inUse`;
  engine counters `arenaDeliveries`/`heapDeliveries` (payloads handed to consuming nodes).
- **Safety**: alignment/bounds-checked offsets, generation-checked handles, header validation
  of everything a producer writes (magic, version, contiguity, rank, element/media type, negative
  dims, overflow, declared length, strides), foreign-offset rejection, RAII reclamation of input and
  output slots on every error path, bounded admission (`arena full` → `Resource`, never
  overcommit), optional input-mutation **detection** (`MVF_VERIFY_INPUTS=1`).
- **ABI**: unchanged v1 layout — 192-byte header, payload at +192, fixed slots, `MVF_ARENA_PATH`,
  `shm.offset`/`out.{offset,capacity}`. Generations are host-side only, so no SDK changes were
  needed and no new wire protocol was introduced.

## Proof: no extra payload copy on the pass-through path

`pass_through_path_moves_no_payload_bytes_between_nodes`:
`cam (arena) → py.invert-transformer → passthrough → py.brightness-classifier`, frame also
recorded, 10 cycles × 64-byte frames:

| Counter | Value | Meaning |
|---|---|---|
| `copiesIn` / `copiesOut` | **0 / 0** | no transfer copy anywhere |
| `transformWrites` | 20 (1280 bytes) | the source and the invert worker writing their own outputs |
| `zeroCopyHandoffs` | 20 | invert and classifier each received an existing slot by handle |
| `arenaDeliveries` / `heapDeliveries` | 40 / 0 | four consumers per cycle, all from shared memory |
| `inUse` after run | 0 | every slot reclaimed |

Contrast (`heap_source_costs_exactly_one_counted_copy_per_frame`): with a heap source the same
graph costs exactly **one** counted copy per frame (`copiesIn = 10`, 640 bytes) at the first worker
and nothing else.

## What cannot be enforced against untrusted native workers

Workers map the arena **read-write** (processors must write their output slot), so a malicious or
buggy native worker can:

- read every slot in the arena (no confidentiality between workers sharing an arena);
- write into its read-only input or into other slots. The host **detects** input mutation when
  verification is on, and re-validates every header it reads, but cannot **prevent** writes.
  `input_mutation_is_detected_when_verification_is_on` shows both: undetected by default,
  `InvalidOutput` with verification;
- the Python SDK maps read-only for classifiers without checkpoint hooks — enforced by the
  child's own mapping, i.e. cooperative.

Stronger guarantees need per-worker arenas or OS-level sealing (memfd seals on Linux, section
object ACLs on Windows) and are not part of this slice. The host's own bookkeeping (free list,
refcounts, generations) is outside the shared mapping and cannot be corrupted by a worker.

## Limitations

- Single slot size (as in the .NET arena); variable-size allocation is still an open design point.
- Backpressure is **refusal** (`Resource` error) — the .NET `stall`/`drop` policies are not ported.
- No checkpoint/restore of arena contents.
- Unsafe code is confined to `mvf-memory/src/arena.rs`; audit notes are in its module docs.
