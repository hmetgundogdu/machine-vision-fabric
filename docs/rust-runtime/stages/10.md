## What was built

- Thresholds committed before the final runs ([../p0-thresholds.md](../p0-thresholds.md), `15d832c`).
- `plc-sim` builtin: one committed effect per cycle; a second commit for the same cycle fails.
- `mvf-rs run`: `--require-gpu`, `--require-oci`, `--max-cutover-us`, PLC duplicate and device
  memory leak checks in `--verify`, cycle-latency percentiles and GPU counters (`{"metrics": …}`).
- `rust/examples/p0/`: the integrated graph for a GPU host (`pipeline-gpu.yaml`, device zero copy
  required) and for the Linux host (`pipeline-linux.yaml`, GPU nodes with CPU fallback), the update
  plan for worker candidates, and never-ready / crashing candidate modules.
- `rust/scripts/p0-testhost.sh`: packages the three detector candidates as OCI images inside the
  Python-free, daemon-free Linux test host, runs the plan, verifies, and checks for leftover
  containers.
- Competitive research with pinned versions and primary sources.

## Bugs found by the integrated runs (fixed)

- Worker entry paths resolved twice when a contract path was relative
  (`relative_contract_paths_resolve_the_entry_once`).
- As root, the default OCI state directory under `/root` (0700) was not traversable by the
  user-namespace root; default is now `/var/lib/mvf/oci`, and an untraversable path is a clear error.
