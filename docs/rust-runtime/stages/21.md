**Status:**

| Platform | Result | Notes |
|---|---|---|

| Linux workers and Linux OCI | **PASS** | runc, no Docker daemon; OCI e2e 27/27, with the containerized SDK on v2 |

## What was built

- **`mvf-ipc`.**
  - The v2 framing: a 24-byte header with magic, version, kind, flags, correlation id,
    generation and a bounded length.
  - Message bodies: fixed binary `execute`, `result`, `checkpoint` and `restore`; JSON for
    `hello`, config, errors and value tails.
  - `mvf-ipc-echo`, a fixture child that speaks v1 or v2 over stdio or fd 3 and has injectable
    faults.
  - The benchmarks and fault-injection suites.
- **Host (`mvf-worker`).**
  - **Negotiation:** a per-launch offer (`MVF_PROTOCOL=2`, `MVF_SESSION`, `MVF_GENERATION`),
    passed into OCI bundles too. Detection by the first byte. The `hello` must carry the launch
    token, and the claimed version must match the framing.
  - **Messages:** a version-independent `HostMessage`.
  - **Receive path:** a direct non-blocking `poll` frame reader on Unix, and a reader thread on
    Windows.
  - **Violations** (malformed, oversized, bad magic, stale generation, wrong session) terminate
    the child at once, with `NodeErrorKind::Protocol`.
  - The remaining deadline is carried in `execute`. `ping`/`pong` and `cancel` exist.
  - **Logs** go through a bounded queue to a delivery thread, with dropped lines counted. v2
    children log on stderr as JSON lines.
  - `WorkerBackend::with_protocol(1|2)`, and `MVF_PROTOCOL=1` as the rollback switch. The
    supervisor logs `ready pid=… protocol=N`.
- **Python SDK.** v2 transport when offered:
  - private duplicates of fd 0 and fd 1, then fd 1 → stderr and fd 0 → null;
  - `struct`-encoded frames;
  - logs to stderr.

  The handler API is unchanged; with v1 the SDK behaves exactly as before.
- **Spec and decision:** [`protocol/worker-v2.md`](../../protocol/worker-v2.md) and
  [ADR-0006](../adr-0006-worker-ipc-v2.md).

### Fault injection (through the real engine and supervisor)

| Fault (on the 3rd request) | Outcome |
|---|---|
| malformed `result` body | `Protocol` ("malformed Result body"), child terminated: 0.37–1.3 s against a 10 s deadline |
| 8 MiB declared body | `Protocol` ("exceeds the limit of 1048576"), refused from the header |
| bad magic | `Protocol` |
| reply with another generation | `Protocol` ("stale generation") |
| `hello` without the launch token | `Protocol` ("unauthorized peer"), refused at readiness |
| hang | `Timeout` at the deadline, child terminated |
| frame left half-written | `Timeout`: the deadline bounds a partial frame |
| exit after half a header | `ProcessExited`, exit code 3 |
| stray `println!` on the process's stdout | the run completes; the text is in the logs |
| log flood, slow consumer | as above: execution not stalled, drops counted |
| cancellation during a hung request | ends within 500 ms of `cancel`, not at the 10 s deadline |
| cleanup | no worker pid survives any of the above |

"Reconnect" means a new process: a broken channel is never resumed, and the failure policy decides
what follows.

## Limits

- **C++ and .NET SDKs still speak v1.** They are served v1 automatically; their v2 ports are part
  2 ([stage 22](22.md)).
- **Windows receives on a reader thread** (pipes cannot be polled). It is correct but pays the
  hop.
- **One request in flight per child.** Concurrency is more children.
- **No descriptor passing yet** (a socket-based feature, if memfd arenas are wanted).
- **`ping` is available but the engine schedules no liveness probe.** Readiness and deadlines
  bound everything today.
- **The launch token is visible to the user's own processes** through the child's environment.
  It binds a launch; it is not a secret.
- **No measurements on industrial edge hardware.** None was available.
