**Who decided:** the maintainer asked for the legacy code to be removed and archived, the README
updated, and the CLI to be called `mvf`. This is #34's "maintainer explicitly approves". The real
Rotary pipeline is being migrated now, and the v1.1.0 legacy CLI is its rollback.

## What changed

- **Archived** (gone from `main`, complete on the archive branch):
  - the engine, the legacy CLI, its worker host and shared-memory transport;
  - egress and its .NET and TypeScript clients;
  - the in-process SDK (`Mvf.Sdk`, `Mvf.Graph`, `Mvf.Abstractions`) and the in-process modules;
  - the legacy tests, `SchemaExporter` and `publish.ps1`;
  - `py-tunable-transformer`, which had no `node.yaml`.

  The inventory is in [legacy-retirement.md](../legacy-retirement.md).
- **Kept:**
  - the .NET worker SDK `Mvf.Worker` and its examples, now the only projects in `Mvf.slnx`;
  - the Python and C++ SDKs and the `py-*` modules;
  - `packages/` (legacy-format fixtures for `mvf import` and the parity script);
  - `web/` (the roadmap site).
- **CLI:** the binary, clap name and every active document, script and workflow say `mvf`. The
  management client name is `mvf` as well. Stage reports and archived evidence files keep the
  name they were written with.
- **CI:**
  - the `.NET build + test` job becomes `.NET worker SDK`, which builds the solution and packs
    `MachineVisionFabric.Worker`;
  - the egress client job is gone.
- **Release:**
  - assets are `mvf-<tag>-<os>.zip` (`mvf`, `mvf-remote`, `mvf-display-host`, license), built
    without debug info, which shrinks the 41 MiB Linux zip;
  - NuGet ships `MachineVisionFabric.Worker` instead of the in-process SDK;
  - the legacy CLI job is gone.
- **Comparison scripts:** `parity-demos.sh` and `bench-baseline.sh` build the legacy engine from
  the archive tag in `.legacy-dotnet/` (git-ignored; `LEGACY_ROOT` to override), and they now
  show build errors instead of exiting silently.
- **Docs:**
  - the README is rewritten around `mvf`: install, quickstart, writing a node (Python, C++, C#
    worker), `node.yaml`, `pipeline.yaml`, and coming from the legacy runtime;
  - the migration guide, the retirement document and `CLAUDE.md`'s engine default are updated;
  - the legacy user guides carry a "legacy document" banner.
